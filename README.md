# Instagram2Shop

Converts an Instagram account into an online shop.

## Features

- Onboarding and dashboard
- Shopify webhooks
- Analytics, billing and notifications

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/instagram2shop.git
cd instagram2shop
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: next lint
